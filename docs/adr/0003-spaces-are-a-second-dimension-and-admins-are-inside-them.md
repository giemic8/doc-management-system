# Spaces are a second visibility dimension, and admins are inside it

Tag ACLs answer "which kinds of document may this group read". They deliberately cannot answer "whose document is this", because admins bypass them by design — and a family system needs both answers. So `documents.space_id` adds a second, orthogonal dimension: every read resolves `tagRule AND spaceRule`, composed in `acl.service.ts` and nowhere else.

A **private** space has exactly one member, its owner. Nobody else reads it, admins included. This is the one place where "admin sees everything" stops: administering the NAS is not consent to read somebody's therapy letters, and the acceptance criterion for this gate is precisely that private content is unreadable to a normal family admin. Consequently an admin cannot add themselves to a private space, cannot nominate its trusted contacts, cannot write or delete in it, and cannot reset another user's password to become them — there is no admin password-reset route at all. A **shared** space is readable by its explicit members, and admins bypass it exactly as they bypass tag ACLs, because a shared household space is content they already administer. `space_id IS NULL` is the common area: everything that existed before this change, governed by tag ACLs alone, so nothing became invisible on upgrade.

Because admins are inside the rule rather than above it, `buildDocumentAclWhereClause` is no longer empty for them. Every read path already spliced it conditionally, so search, RAG retrieval, analytics, contracts, the calendar feed, the trash listing and the document list needed no change; the DATEV and GoBD export queries, which had no ACL clause at all, gained the space half explicitly. A private family space is not the business's records, so excluding it from a tax export is correct rather than a gap — but the exclusion is now written down at the query instead of being an accident of who ran it. The audit log takes the opposite trade: rows about unreadable documents keep their action, actor and timestamp and lose only the title, since hiding that something happened would defeat an audit log while showing the title would leak the content it records.

Emergency access is the only way into somebody else's private space. It requires a trusted contact the owner nominated **in advance**, approval by a **second, different** trusted person (a database CHECK enforces `approved_by <> requested_by`, so no future code path can approve its own request), and it **expires** on a clock that starts at approval, capped at 72 hours. It is **read-only**: reading someone's records to act for them is the need; changing or deleting them while they cannot object is not. Every step is audited, and so is every document actually opened under the grant — the approval says access was possible, the use record says what was read. Revocation flips the row's status, which is the same predicate the visibility SQL already tests, so a revoked grant closes the space in the same request.

Account recovery exists so that none of this is undone by the obvious shortcut. The natural way to let a family member back into a locked account is an admin password reset, which would hand the admin everything a private space exists to withhold, indistinguishably from the owner logging in. Instead, owners generate their own recovery codes, shown once and stored as bcrypt hashes, redeemable once each, audited on use, and never mintable by anyone else. Redemption restores the password factor only and deliberately leaves MFA in place — a lost second factor is what the separate MFA backup codes are for — so a stolen recovery code still does not open an MFA-protected account.

Two consequences are accepted rather than worked around. Splitting a document keeps the parts in the source's space and merging across spaces is refused outright, because a derived file that lands in the common area publishes the original. And a guest share link stops working once its creator is no longer in the document's space: a share link is a delegation of one person's access, so when nobody is vouching for it, it opens nothing.
